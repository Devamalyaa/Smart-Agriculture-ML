# Smart Agriculture Yield Prediction using Machine Learning

## Overview
This project predicts crop yield using machine learning models such as:
- Linear Regression
- Decision Tree
- Random Forest
- KNN

## Features
- Data preprocessing
- Model comparison
- Evaluation metrics (R², MSE, MAE)
- K-Means clustering

## Dataset
Crop yield dataset with environmental and agricultural features.

## Tools Used
- Python
- Scikit-learn
- Pandas
- Matplotlib
